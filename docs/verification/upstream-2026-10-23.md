# Upstream integration on 23 October 2026

This merge combines fork commit `bf9f3dee` with upstream commit `d458733e`. Their common ancestor is upstream `v0.18.0`, `e6be760b`. Upstream includes the reviewed versions of PRs #133 through #141 and 15 subsequent feature changes. The app version remains `0.18.0`.

## Behavior preserved

The fork retains Needle, inline History recovery, explicit cleanup outcomes, the configurable final-cleanup wait limit, cleanup quality and profile formatting, dictation timing data, target-window safeguards, and isolated deployment and upgrade verification. MIGraphX and WebGPU remain available alongside upstream's acceleration choices. Existing SDK enum values retain their order.

The shared features use the reviewed upstream behavior. This includes ChatGPT sign-in, shortcut capture and key validation, provider selection, explicit model-catalog refresh, localization and accessibility, text processing without usage writes, and Vulkan loading and packaging.

Final cleanup retains the fork's explicit user wait limit. Zero means no final deadline. Speculative drafts have a separate budget and never hold a shared request gate. Waiting for a matching draft consumes the explicit final budget. An exhausted budget returns Light cleanup with a TimedOut outcome and leaves the original transcript available for recovery. Preview input passes through the same stages that precede final cleanup.

The new appearance resources also apply to the fork's History recovery panel. Language changes preserve active operations and custom status messages while refreshing known status labels.

## Conflicts and compatibility fixes

Git reported 58 conflicting files, including 14 add/add conflicts. Manual review also found semantic conflicts in files that Git merged automatically.

- Old shortcut recorder methods remained beside the reviewed implementation. The merge removes those duplicates and keeps the reviewed parser's supported-key boundary.
- The two catalogs each contained 38 plugins, but their union contains 39 because the fork has Needle and upstream adds GitHub Copilot. Catalog and manifest checks now expect that union.
- Upstream removes the final-cleanup timeout setting. The fork deliberately retains it. The corresponding settings test verifies the retained contract, while the upstream no-default-deadline service test still passes.
- The text API retains fork cleanup outcome metadata and adopts upstream normalization, language handling, per-step timing, and no-usage-write processing.
- Sherpa's managed binding moves from 1.12.23 to 1.13.8 for Qwen3-ASR. Both custom native patches and build scripts now target 1.13.8. A stale source checkout fails before a payload is written. Both custom native builds completed.
- Qwen3-ASR retains its upstream CPU execution policy. It does not initialize a custom GPU runtime merely because a GPU preference was saved.
- The release workflow previously omitted WebGPU from the registry ZIP. It now builds and copies both custom Sherpa runtimes and validates their required ZIP entries. The upstream Vulkan ZIP checks remain in place.
